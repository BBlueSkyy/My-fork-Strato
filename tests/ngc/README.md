# NGC IPC handlers

Run `bash tests/ngc/run.sh`. This builds the production NGC IPC handlers and
dictionary filter under ASan/UBSan. Fixtures are generated by the independent
`tests/ngc_dictionary` format encoder and contain synthetic tokens only.

The host boundary substitutes `DeviceState`, request/response storage and a
dispatcher that consumes the production command-registration macro. Requests
use a 0x100-byte wire-layout TLS buffer, realistic headers/padding/domain fields,
and the production parser's overstated non-domain raw size. The tests
exercise handler argument parsing and response payloads; they do not decode
kernel HIPC packets. A supplied data-source callback reads real-format fixture
files. The unused default provider constructor is linked with a test stub;
`tests/ngc_content` separately tests the production provider.

The suite verifies dictionary-backed positive/negative matches, region union,
boundary matching, mask modes/counts, true raw argument/TLS/domain bounds,
required A/B map-alias descriptors and rejected mixed/wrong transport, missing
descriptors, UTF-8/NUL ordering, unavailable data, the 512-character mask limit,
version byte order/fallback, Reload, and explicit unsupported errors.
