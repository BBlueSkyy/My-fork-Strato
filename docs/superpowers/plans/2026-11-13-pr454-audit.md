# PR #454 semantic audit implementation plan

**Goal:** Audit reserved TIC handling without reverting Kirby's sampled-texture workaround.
**Architecture:** Keep the reserved-target sampled compatibility path, distinguish it from a decoded texture with missing backing, and fail closed for storage and hosts unable to bind dimensionless null images. Exercise production functions in host fixtures; document the limits instead of claiming Maxwell equivalence.
**Tech stack:** C++20, Python, ASan/UBSan; pinned shader compiler e972cae.
**Spec:** User's eight-point audit request for PR #454; no merge and remain Draft.

## Global constraints
- No game-specific code, shader edits or broad synchronization/cache redesign.
- Preserve the current sampled null behavior on nullDescriptor hosts.
- Invalid descriptors with mapped base addresses remain fatal.
- GMMU base-address presence is not a proof of texture extent or hardware semantics.

## Review focus
- Reserved descriptors must never silently drop storage writes.
- Without nullDescriptor, a 2D placeholder must not satisfy arbitrary reserved-target sampled bindings.
- Valid 0..8 descriptors retain their dimensionality and bypass the reserved-target lookup.
- Null results must be reevaluated after descriptor replacement/remapping.
- Pipeline reuse after a descriptor-type change remains a separate architectural risk and must be explicitly demonstrated/reported.
