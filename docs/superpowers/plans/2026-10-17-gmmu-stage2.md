# GMMU stage 2 — sparse resources and disjoint buffers

Base: 17b39196, same branch/PR354. User authorizes implementation/publication.
No changes to PR234/244/353, no merge, no Actions monitoring.

Architecture: retain typed GMMU snapshots. Mirror resident physical spans through
mremap aliases, and allocate private zero holes. Do not turn unmapped spans into
sparse spans. Resource consumers retain ordered layouts, trap resident bytes only,
ignore guest writes to missing pages and revalidate on remap. Overlapping staged
buffers need explicit authority reconciliation at the outer submit/retry boundary;
never submit inside preparation. Resident single-span paths retain their fast path.

Review focus: nonresident first/last pages; duplicated physical pages; partial
views crossing holes; shared physical aliases and pending writes; remap while
bindings cached; no repeated clean copies or unnecessary submissions.

Mirror regression: missing API fails before implementation; production method passes
ASan/UBSan with real memfd/shared mappings, reversed resident pages, sparse zero
isolation, bidirectional resident writes and invalid/sentinel rejection.

Buffer validation: production-body ASan/UBSan cache, alias authority, physical
pending writes, direct/staged copies, delegates/coalescence lifetime, and complete
upload/DMA/constant-buffer retry boundaries pass; conditional rendering 20/20.
Sparse texture validation: real Vulkan + synchronization validation on native
resident overlaps, missing first/middle/all pages, unaligned partial spans, remap,
current-executor unsubmitted writers, and independent resident MRT writers. Exact
layout aliases, promotion/mip growth, pitch/BC regressions remain covered.

Deliberate limits: dense Vulkan images cannot discard missing-page shader writes;
sparse textures are read-only. GPU buffer writes crossing holes and writes through
repeated physical spans fail closed. Sparse texture materialization remains within
the existing proven color-layout bounds; aliases with discarded guest padding
cannot be reconstructed. Aggregate buffer backings retain stable raw view/delegate
lifetimes and are cached by ordered mapping shape. No native sparse Vulkan path.

TIC follow-up: both lookup cache levels are invalidated on address-space/mapping
generation changes. Descriptor pools retain the contiguous resident fast path;
fragmented pools resolve only the queried descriptor, so an unused unmapped tail
does not hide valid indices. Only split/sparse descriptors require a bounded 32-byte
read. Sparse data mappings reach TextureManager with typed residency; truly
unmapped descriptor/data bytes keep their legitimate diagnostics. No UE4-specific
cause is claimed without a game trace. Queued descriptors retain Vulkan handles
and texture backing, and DRAW_TEXTURE retains its shared view; no global submit
was introduced for TIC invalidation.
