Constraints: preserve resident fast path, sparse zero/discard and unmapped faults;
no shared PR edits, global waits, copy mirrors or allocator rewrite.
Review focus: AS endpoints/zero sizes; L2 tail preservation; partial remap extents;
sparse copy destinations/callbacks; cached mappings after same-VA replacement.

Ledger: each published task records SHA and checks here. User explicitly authorizes

Task 1 evidence: sparse/remap/L2 assertions fail on master; all pass after fix.
ASan/UBSan: 5000 randomized updates/25000 queries, both 40-bit GPU and 32-bit
host1x specializations, upper endpoint and alignment rejection pass.

Task 2a: Write(span) callback failed before fix; sparse Copy destination writes
0xCAFEBABE under ASan before fix. Bounded state-aware I/O and Copy replace invalid
pointer arithmetic; MapSparse no longer stores a sentinel. Production tests pass.

Task 2b: production CachedMappedBufferView::Update fails same-IOVA remap before
fix; passes after generation/AS-identity checks. Contiguous fragments reuse a
full view, disjoint fragments retain a diagnosed resident prefix; no scratch copy.

Consumer integration: GPFIFO checks mapping generations at pushbuffer boundaries
and invokes existing binding-cache invalidators without submitting/resetting nodes,
allocator, cycles or hazards. Nonresident pushbuffers use bounded Read instead of
borrowing null physical spans. Host-only texture fallback no longer dereferences an
empty guest; the optional assertion fails on f5d70630 and passes after the guard.
The null fallback image admits storage usage. This does not materialize sparse
texture resources or solve #234's unresolved loading freeze.

Validation boundary: the optional gpu_backing_promotion host harness on master
fails compilation on third-party Vulkan-Hpp deprecated-copy warnings with Clang18;
it is outside the workflow and no Vulkan-runtime success is claimed here.
tests/gpu_usage exists only on #353, not this master-based branch. Existing pitch,
query/conditional/draw-texture and view-range tests are the relevant baseline checks.

Final review: two Important findings, both reproduced before their fixes:
- Appending resident pages reused a shorter shader mirror/trap at the same PA.
  Mirror keys now include extent, retaining older binary spans/traps. The test
  extends a mapping, looks up page two, modifies it and verifies trap invalidation.
- Sparse boundary refresh scaled with a whole reservation for each small tile.
  Sparse index entries now remain empty and resolve through authoritative intervals;
  resident fast entries remain O(1). Test-only SegmentTable boundary accounting
  verifies that replacing one 4 KiB tile touches the same bounded index span in
  16 MiB and 16 GiB reservations, while preserving sparse/resident classifications.
Both regressions RED->GREEN, full GMMU ASan/UBSan suite green. No re-review.

Remaining integration/device boundary: production deferred-draw/query and descriptor
retention callbacks are reused at pushbuffer boundaries; the host test checks the
notification body and no Submit, not every Android callback with in-flight work.
Concurrent remaps while a pushbuffer is already executing still require the
application's ordering; there is no new global scheduler or GPU wait.
