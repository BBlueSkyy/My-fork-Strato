# PR 420 semantic review and validation

Base retained: Strato `5bce13eb`, shader compiler `e194633c`. Pokémon Legends:
Z-A v1.0.0 reached name entry on the reported Moto G100 after the experimental
array-coordinate change. This review does not establish that NGC causes the
later Qualcomm compute-pipeline failure.

## Grounded changes

- Compiler `9dda0d5`: SURED operation reads bits 24–26, independently from size
  bits 20–22; the former field overlapped and translated a real MIN/U32 encoding
  as ADD. Existing array coordinates are preserved. `Image1D` is declared for
  1D storage images, resolving 52 validator failures among 156 generated modules.
- NGC: real firmware-format gzip/succinct dictionaries, bounded ASCII Check/Mask,
  region masks, version bytes and commands 0–3. Missing data returns an error.
  See [NGC limits](pokemon-za-ngc.md): Unicode/canonicalization and some long
  matches remain unsupported; this is not a complete firmware NGC implementation.
- NGC content: existing registered system-content location plus an explicit
  extracted RomFS source. Select only title `0100000000000823` Data content;
  reject ambiguous archives rather than choosing by directory order. A scoped
  prewalk rejects cyclic/out-of-range metadata before the legacy RomFS walker.
- Compute: default-off bounded candidate capture, exact effective SPIR-V and
  guest input, descriptors/profile/device metadata and original Vulkan result.
  No workaround or changed pipeline creation flags. See
  [capture and export](pokemon-za-compute.md).

## Host results

- 612 real instruction-translation combinations plus rejected/edge encodings.
- 156 optimized SPIR-V modules: operation, image format, Device scope/Relaxed
  semantics and `spirv-val --target-env vulkan1.1spv1.4` all pass.
- NGC dictionary, IPC and content-reader suites pass; IPC/content use ASan/UBSan.
- Compute store ASan/UBSan, four offline-validator tests, Vulkan-Hpp boundary
  syntax checks and settings regression pass.
- Structured SSBO safety fixtures and 96 actual SSBO binding paths pass.
- Software keyboard and production NCA/VFS regression suites pass.
- Sampled-layout and submission regression suites pass.

Two broader existing harnesses fail identically when run from the unmodified
`5bce13eb` snapshot: `tests/fssrv/run.sh` reports "cache size returned fabricated
output" in "proxy validation and state"; `tests/gpu_conditional/run.py` cannot
compile its facade because `ActiveState::InvalidateIndexBuffer` is missing.
These unrelated failures are retained, not reported as passing. The backing-promotion harness also fails with GCC on existing out-of-order
`vk::ImageMemoryBarrier` designated initializers in unchanged texture code.
Initial missing host dependencies were resolved; this broader harness is not
reported as passing.

LeakSanitizer cannot inspect this environment's `/proc` threads. Tests needing
it disabled retain address and undefined-behavior instrumentation. The complete
Android build and game/device execution are not covered by these host checks.

## Device validation

Install the ARM64 DevRelease generated by the existing PR Build workflow. Keep
the same game/save/driver/settings for the first reproduction. Enable Settings
→ Debug → Capture compute pipeline diagnostics before launching. Reproduce the
name-entry path once; export the log and the four capture files before launching
another emulation session. A successful shader validation is not proof that a
Qualcomm pipeline compiles or executes correctly. No failing game shader was
available in the supplied logs, so that cause remains unresolved.
